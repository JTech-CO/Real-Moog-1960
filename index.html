LIVE ROUTING

PATCH CORDS 0

01

소리와 제어 전압은 다릅니다

검은 AUDIO 잭은 실제 파형을, 황색 CV 잭은 노브를 자동으로 움직이는 값을, 적색 GATE 잭은 음의 시작과 끝을 전달합니다.

02

패치가 곧 프로그램입니다

VCO → Mixer → Filter → VCA → Output이 기본 흐름입니다. Keyboard CV를 VCO에, Gate를 Envelope에 연결해야 건반이 음높이와 음량을 제어합니다.

03

한 선만 바꿔도 결과가 달라집니다

LFO를 OSC에 연결하면 비브라토, Filter에 연결하면 자동 스윕이 됩니다. Envelope를 VCA에 연결하면 눌렀다 떼는 음표가 생깁니다.

PATCH SCHOOL · LESSON 01

첫 소리를 만드는 7개의 케이블

  1. OSC 1 SAW → MIXER INPUT 1
  2. MIXER OUT → FILTER AUDIO IN
  3. FILTER OUT → VCA AUDIO IN
  4. VCA OUT → OUTPUT SIGNAL IN
  5. KEYBOARD PITCH CV → OSC 1 CONTROL INPUT
  6. KEYBOARD GATE → ENVELOPE 1 TRIGGER
  7. ENVELOPE 1 OUT → VCA CONTROL IN

출력 잭에서 입력 잭까지 드래그하거나 두 잭을 차례로 클릭합니다. 케이블을 더블클릭하거나 아래 PATCH CORDS 목록의 ×를 누르면 제거됩니다.
